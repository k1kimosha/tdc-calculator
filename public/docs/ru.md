## Как работать с калькулятором

Все расчёты строятся на базе **формул**, которые можно менять в разделе *Справочник → Редактируемые калькуляторы*.

1. Откройте нужную вкладку: **Дистанция**, **Скорость**, **КУЦ** или **О’Кейн**.
2. Выберите класс цели из выпадающего списка — высота (мачта/труба) и длина подставятся автоматически. Если своего класса нет, введите значения вручную.
3. Для **Дистанции** укажите ориентир (мачта или труба) и кратность (×1,5 или ×6), затем введите риски — получите дистанцию в метрах. Можно и наоборот: ввести дистанцию и получить нужные риски.
4. Для **Скорости** замерьте время прохода цели от носа до кормы и введите его — скорость рассчитается по длине цели.
5. Для **КУЦ** введите видимую длину в рисках (умножаются на дистанцию) либо сразу курсовой угол, выберите борт (Л/П) — получите курсовой угол цели.
6. Для **О’Кейна** укажите скорости цели и торпеды, прицельную дистанцию и КУЦ — получите угол упреждения, пеленг на выстрел и время хода торпеды.
7. Если стандартная формула неудобна — отредактируйте её в справочнике, результат обновится на лету.

## Синтаксис формул

Выражение — это математическая запись, в которой используются **переменные**, **операторы**, **функции** и **константы**.

- Переменные берутся из своего калькулятора: `h`, `k`, `r`, `d`, `l`, `t`, `spd`, `v`, `a`, `vt`, `vs`, `lead`, `c`.
- Операторы: `+` `−` `*` `/` `%` `^`. Возведение в степень `^` правоассоциативно: `2^3^2` = 512.
- Скобки `( )` меняют порядок действий, запятая разделяет аргументы функций.
- Константы: `pi` (π), `e`, `tau` (2π).
- Функции: `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `atan2`, `sinh`, `cosh`, `tanh`, `sqrt`, `cbrt`, `abs`, `floor`, `ceil`, `round`, `trunc`, `sign`, `ln`, `log`, `log2`, `exp`, `min`, `max`, `clamp`, `rad`, `deg`.
- Тригонометрия считается в **радианах**: 45° можно записать как `pi/4` или `rad(45)`.
- Имена переменных и функций пишутся **без учёта регистра**: `H*k/r` равно `h*k/R`.
- Десятичные дроби — через точку (`1.5`), поддерживается экспоненциальная запись: `1e3` = 1000.

Пример — время хода торпеды: дистанция в метрах, делённая на скорость торпеды, переведённую в метры в секунду:

```js
d / (vs * c)
```

## Математический базис

**Дистанция:**

```formula
D = H × K ÷ R
```

```js
h*k/r
```

**Риски по дистанции:**

```formula
R = H × K ÷ D
```

```js
h*k/d
```

**Скорость цели:**

```formula
V = L × 1,94 ÷ T
```

```js
l/t*1.94
```

**Видимая длина:**

```formula
Lв = R × D ÷ 1000
```

```js
r*d/1000
```

**КУЦ по видимой длине:**

```formula
AOB = arcsin(Lв ÷ L)
```

```js
asin(v/l)*180/pi
```

**Угол упреждения (метод О’Кейна):**

```formula
β = arctan(Vц ÷ Vт)
```

```js
atan(vt/vs)*180/pi
```

**Общий случай упреждения:**

```formula
β = arcsin((Vц ÷ Vт) × sin(AOB))
```

```js
asin(vt/vs*sin(aob*pi/180))*180/pi
```

**Время хода торпеды:**

```formula
t = D ÷ (Vт × 0,5144444)
```

```js
d/(vs*c)
```

## Работа со справочником

1. Справочник хранится в **localStorage** браузера — сервер не нужен, данные переживают перезагрузку страницы.
2. **Классы кораблей** — параметры целей (длина, высота, осадка, скорость, палубное орудие). Кнопка «Добавить» создаёт свой класс.
3. **Сценарии дистанций** — раздельные рекомендации для **надводного** и **подводного** положения, строки рисков кликабельны.
4. **Дополнительные рекомендации** — заметки по работе с TDC и идентификации.
5. **Редактируемые калькуляторы** — формулы четырёх калькуляторов с живой проверкой синтаксиса и списком переменных.
6. **Экспорт/импорт** — кнопки «Экспорт JSON» и «Импорт JSON» сохраняют весь каталог (включая формулы) в файл; «Сбросить данные» вернёт заводские значения.
